# Diagram implementation

The AWS Production Architecture article uses a shared HTML/CSS visual system. Topology figures use inline SVG connector layers with semantic HTML nodes, while conceptual and process figures use responsive cards and flows. This keeps official service icons readable, allows simple visuals to stack on mobile, and limits horizontal scrolling to genuine topology.

AWS service icons are stored in `../icons/aws/` and come from the official AWS Architecture Icons package dated April 30, 2026: https://aws.amazon.com/architecture/icons/

The compositions, connector layouts, labels, and generic line icons are original. The supplied reference material was used only as a subject-coverage baseline; no source artwork is included.
